# Kuladeep — Developer Portfolio

A modern, responsive developer portfolio built with **React, Vite, and Tailwind CSS**. It showcases my technical skills, projects, and journey as a developer.

## ✨ Features

* **Responsive Design** — Works across desktop, tablet, and mobile devices.
* **Hero Section** — Introduction and quick navigation to projects and contact details.
* **About Me** — Background, interests, and career goals.
* **Technical Skills** — Overview of technologies and tools I work with.
* **Projects Showcase** — Highlights selected development projects.
* **Contact Section** — Quick links to email and professional profiles.
* **Resume Download** — Downloadable resume.
* **Smooth Navigation** — Easy navigation between portfolio sections.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/kuladeepb/My-portfolio.git
```

### 2. Navigate to the project folder

```bash
cd My-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

### 5. Build for production

```bash
npm run build
```
